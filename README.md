# Photospace

React + Vite site built from the Photospace layout. Mobile-first and responsive, with automatic dark mode.

## Run it

```bash
npm install
npm run dev
```

Open the local address shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

The output is in `dist/`.

## Edit content

All text (slides, team, services, about) lives in `src/data.js`. Colours are CSS variables at the top of `src/index.css`.
